RelayServer

v0.0.13 · 4.5 MB

Native Apple NAC validation daemon for 32-bit architectures (iPhone 5, iPhone 5c, iPad 4). Handles direct kernel Mach messages to com.apple.absd and provides local hardware telemetry.

  • Native Mach IPC with absd using entitlement-verified client ID 772496756
  • MobileGestalt battery capacity and live external power state reporting
  • Configurable Home Assistant REST push telemetry (sensors for health, pairing code, battery)
  • Atomic port 8080 listener mutex to prevent concurrent instance conflicts
  • Embedded web dashboard for pairing code display and configuration
