OpenBubbles Relay Repository

Community APT distribution providing platform enhancements, 32-bit legacy iOS ports, and hardware telemetry for OpenBubbles Relay Server.

Upstream Attribution & Scope Notice

The core relay logic, network protocol, and fundamental codebase are the property of OpenBubbles. This project is not developed independently and will not diverge into an independent codebase; all core logic remains upstream OpenBubbles property. This repository strictly provides architecture-specific ports (e.g. 32-bit armv7s legacy iOS), daemon lifecycle management, and Home Assistant telemetry.

RelayServer (universal)

v0.0.16-4 · 6.6 MB

OpenBubbles RelayServer daemon for rootful jailbreaks (dpkg architecture iphoneos-arm). From v0.0.16-1 the binary is universal: the armv7s slice serves legacy 32-bit devices (iPhone 5, iPhone 5c, iPad 4 on iOS 10) and the arm64 slice serves 64-bit devices such as the iPhone 6 on iOS 12. Enables dedicated background relay operation with local status monitoring.

  • Continuous background registration and relay operation under launchd
  • No bundled SSH host keys: devices still using the keys shipped by 0.0.6 – 0.0.16-1 get fresh ones generated on install
  • Automatic Wi-Fi IP detection and dashboard link printed directly in Cydia / Sileo console
  • Real-time battery level and external charging state monitoring
  • Configurable Home Assistant REST push telemetry (sensors for health, pairing code, battery)
  • Hardened daemon lifecycle: singleton lock, safe IPC, atomic config persistence, and idle recovery
  • Embedded web dashboard for pairing code display and configuration

RelayServer (64-bit)

v0.0.16 · 1.1 MB

OpenBubbles RelayServer daemon compiled natively for 64-bit iOS devices, published under the iphoneos-arm64 architecture. Package managers on rootful jailbreaks do not offer this architecture; use the universal package above there. Features full parity with Home Assistant push reporting, hardware telemetry, and daemon locking.

  • Continuous background registration and relay operation under launchd
  • Native 64-bit ARM execution with minimal resource footprint
  • Automatic Wi-Fi IP detection and dashboard link printed directly in Cydia / Sileo console
  • Real-time battery level and external charging state monitoring
  • Configurable Home Assistant REST push telemetry (sensors for health, pairing code, battery)
  • Hardened daemon lifecycle: singleton lock, safe IPC, atomic config persistence, and idle recovery
  • Embedded web dashboard for pairing code display and configuration
